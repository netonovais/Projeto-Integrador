# Plataforma Digital do Grupo de Pesquisa R.E.G.I.I.M.E.N.T.O.

## Sobre o projeto
Este projeto tem como objetivo o desenvolvimento de uma plataforma digital para o Grupo de Pesquisa **R.E.G.I.I.M.E.N.T.O.** da **Universidade de Brasília (UnB)**.

A proposta da plataforma é atuar como principal canal de comunicação entre o grupo, a comunidade acadêmica e a sociedade, reunindo informações institucionais, pesquisas, publicações, eventos e indicadores analíticos em um único ambiente digital.

---

## Contexto
O grupo de pesquisa **R.E.G.I.I.M.E.N.T.O.**  
(**Research Expert Group for Intelligent Information in Multimodal Environment using Natural Language Technologies and Ontologies**) atua desde 2009 em iniciativas ligadas à Arquitetura da Informação, Processamento de Linguagem Natural, Engenharia de Ontologias, Multimodalidade, Deep Learning e Ciência Arquivística Computacional.

Além disso, o grupo participa de redes e projetos relevantes, como o **INTERPARES TRUST AI**, e possui histórico de forte atuação acadêmica, com mestres e doutores titulados ao longo dos anos.

Apesar de sua relevância, existe a necessidade de uma solução digital capaz de centralizar e organizar melhor suas informações, facilitando o acesso para estudantes, pesquisadores e demais interessados.

---

## Problema
Atualmente, as informações sobre o grupo, suas pesquisas, eventos, produções acadêmicas e indicadores não estão necessariamente centralizadas de maneira clara, responsiva e acessível.

Isso pode gerar:
- dificuldade de acesso às informações;
- baixa visibilidade das atividades do grupo;
- menor engajamento de novos estudantes e pesquisadores;
- dificuldade na divulgação de eventos, linhas de pesquisa e resultados acadêmicos.

---

## Objetivo geral
Desenvolver uma plataforma digital responsiva para o grupo **R.E.G.I.I.M.E.N.T.O.**, com foco em:

- centralização de informações institucionais;
- divulgação de pesquisas, eventos e publicações;
- apoio ao engajamento de estudantes, voluntários e pesquisadores;
- disponibilização de dashboards com dados analíticos sobre a produção e atuação do grupo.

---

## Objetivos específicos
- Criar uma página institucional com histórico e apresentação do grupo;
- Exibir linhas de pesquisa e áreas de atuação;
- Disponibilizar informações sobre corpo docente e discente;
- Organizar um repositório de teses, dissertações, artigos e produções acadêmicas;
- Divulgar workshops, colóquios, seminários e demais eventos;
- Criar uma área para alunos e interessados;
- Integrar dashboards para visualização de dados sobre a Arquitetura da Informação Multimodal no Brasil.

---

## Público-alvo
Este projeto é voltado para:

- estudantes interessados em pesquisa;
- docentes e discentes vinculados ao grupo;
- pesquisadores da área;
- comunidade acadêmica;
- sociedade interessada em ciência, tecnologia e educação digital.

---

## Funcionalidades previstas
A plataforma poderá conter as seguintes funcionalidades:

- Página inicial institucional;
- Apresentação do grupo e seu histórico;
- Seção de linhas de pesquisa;
- Listagem dinâmica de docentes e discentes;
- Repositório de publicações acadêmicas;
- Agenda de eventos;
- Área para alunos/interessados;
- Painéis e dashboards interativos;
- Design responsivo;
- Identidade visual alinhada à UnB.

---

## Requisitos iniciais
### Requisitos funcionais
- O sistema deve exibir informações institucionais do grupo;
- O sistema deve apresentar as linhas de pesquisa;
- O sistema deve listar publicações e produções acadêmicas;
- O sistema deve divulgar eventos e atividades;
- O sistema deve disponibilizar dashboards com dados analíticos;
- O sistema deve permitir navegação simples e organizada.

### Requisitos não funcionais
- O sistema deve ser responsivo;
- O sistema deve possuir interface clara e acessível;
- O sistema deve seguir identidade visual institucional;
- O sistema deve apresentar boa usabilidade;
- O sistema deve organizar as informações de forma intuitiva.

---

## Tecnologias sugeridas
As tecnologias poderão ser definidas conforme a evolução do projeto. Algumas opções iniciais são:

- **Frontend:** HTML, CSS, JavaScript
- **Frameworks possíveis:** React, Next.js ou outro framework web
- **Backend:** Node.js, Python ou outra tecnologia definida pela equipe
- **Banco de dados:** MySQL, PostgreSQL ou MongoDB
- **Versionamento:** Git e GitHub
