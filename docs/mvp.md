
# MVP - Produto Mínimo Viável

## Objetivo do MVP

Entregar uma versão inicial funcional da plataforma digital do grupo R.E.G.I.I.M.E.N.T.O., contendo os recursos essenciais para apresentar o grupo, divulgar conteúdos e permitir acesso inicial a informações institucionais e analíticas.

## Funcionalidades do MVP

- Página inicial institucional
- Seção "Sobre o Grupo"
- Exibição das linhas de pesquisa
- Listagem de membros
- Repositório inicial de publicações
- Agenda de eventos
- Formulário de contato/interesse
- Dashboard inicial com dados relevantes

## O que fica fora do MVP

- Painel administrativo completo
- Controle avançado de usuários
- Dashboards complexos e interativos em larga escala
- Integrações externas avançadas
- Área privada robusta para alunos e pesquisadores

## Justificativa do MVP

A definição do MVP permite focar nas funcionalidades essenciais para validar a proposta do produto, reduzir complexidade inicial e garantir uma primeira entrega com valor real para os usuários.
